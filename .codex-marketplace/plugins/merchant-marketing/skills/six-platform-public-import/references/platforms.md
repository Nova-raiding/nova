# 六平台公开页面适配参考

以下是解析策略，不是平台 API 或授权说明。页面结构会变化，解析失败时必须保留阻断状态。

| 平台 | 主机名示例 | 优先字段 | 常见阻断 |
| --- | --- | --- | --- |
| 京东 | `item.jd.com` | SKU、标题、价格、主图、详情图、规格、店铺 | 动态价格、验证码、详情懒加载 |
| 淘宝 | `item.taobao.com` | 标题、价格、SKU、主图、详情、店铺 | 登录墙、风控、短链跳转 |
| 天猫 | `detail.tmall.com` | 标题、价格、SKU、主图、详情、品牌 | 登录墙、区域/活动价格 |
| 拼多多 | `mobile.yangkeduo.com`、`yangkeduo.com` | 标题、价格、规格、主图、详情 | 分享链接过期、登录/验证码 |
| 小红书 | `xiaohongshu.com`、`xhslink.com` | 页面标题、公开图片、公开描述 | 登录墙、短链失效、内容权限 |
| 抖音 | `haohuo.jinritemai.com`、公开商品页 | 标题、价格、规格、公开图文 | 地域/登录限制、动态接口 |

规则：

- 价格若同时出现划线价、活动价和券后价，分别记录并标注页面标签，不把活动价当永久价格。
- 规格和 SKU 必须保留页面原始名称；无法确认库存时不填 0，标记为未知。
- 图片 URL 需要逐个验证可访问性；失效或防盗链图片保留缺失原因。
- 详情文案只做摘要和结构化事实提取，不复制竞品长文本；自有商品页面也要标注“来源页面待商家确认”。
- 页面访问时间、最终 URL 和读取方式必须进入来源元数据。

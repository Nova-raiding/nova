# Amazon 商品摄影规划

本技能将已确认的商品事实和目标转为可审阅的商品图片制作计划，供商家、摄影师或设计师执行。只处理规划和验收文本；图片生产、编辑、生成、查询、上传、归档与交付均由 `merchant-marketing` 主技能根据当前 Merchant MCP 工具和服务端门禁处理。

## Store Nova 路由与事实门禁

- 仅在 `merchant-marketing` 已核验当前工作区，并将请求路由到 Amazon 图片策划或摄影 brief 后使用。用户要求生成、精修、上传、导出或发布时，回到主技能；本技能不得直接调用任何媒体工具。
- 商品身份、规格、配件、卖点、受众、素材、工作区和权限只以 Merchant MCP 当前返回结果及商家明确确认的事实为准。不得网页搜索商品、竞品或平台规则，不抓取链接，不以行业常识补成商品事实。
- 把每项输入标为“已确认”“创意建议（待商家确认）”或“未知/待核对”。若关键信息缺失，集中询问商家；不能确认的项目保留未知，不阻断其余可规划部分。
- 只用获准素材作为商品外观参考。第三方照片、品牌、人物和商标须有商家提供的授权说明；权限或素材状态不明时不建议纳入计划。

## 图片组规划

不规定固定张数。根据商家确认的 marketplace、类目、页面位置、可用素材与目标，先说明每张图要回答的一个买家问题，再给出经确认事实支持的序列。可考虑：

1. 主图：明确呈现售卖商品及实际包含物；平台/类目规则未核验时标记“待核对”。
2. 核心用途或利益：只表达已有事实支持的用途，不承诺未经证实的结果。
3. 细节与结构：展示可核验的部件、材质、尺寸或兼容性。
4. 真实使用场景：仅选择商品资料或商家确认支持的场景和动作。
5. 包装与包含物：准确区分商品、包装、可选件和不包含的道具。
6. 变体与比较：只对比已确认的 SKU/属性，标清比较范围，不添加未验证的竞品信息。

删去没有证据、素材或版位需求支持的画面，不为凑数新增图片，也不承诺点击率或销量提升。

## 商品外观锁

在每张图的 brief 中复用同一份已确认外观锁，至少检查：

- 外形、比例、朝向和当前可见状态；
- 颜色、材质与表面质感；
- Logo、标签和印刷文字的内容与位置；
- 可见部件、随售配件、SKU 差异和包装内物品；
- 不得添加、移除或改动的内容。

未知的尺寸、材质、隐藏面结构、配件、认证和功能不得推断。若素材之间相互矛盾，列明冲突并请求商家核实，不替商家选择版本。

## 平台规格和验收

逐张记录 marketplace、类目、投放位置、目标像素尺寸、宽高比、格式、文件大小要求及其证据来源。规格只可来自商家确认的信息或 Merchant MCP 当前返回的权威要求；来源缺失或无法确认时写“待核对”，不得沿用记忆中的 Amazon 或其他平台规格，也不得声称合规通过。

实际候选图只有在 Merchant MCP 返回对应资源后才能进入验收。先核对工具实际提供的尺寸/格式/机器 QA 结果；缺少机器证据时只能报告人工视觉观察。人工检查重点包括商品外观锁、配件数量、文案准确、移动端可读性、裁切/留白和透明部件、反光、阴影、小字等高风险细节。人工意见不能伪称为机器检查或平台审批。

涉及正式图片生成、局部编辑、费用、素材扫描、权益或用户批准时，完全遵循 `merchant-marketing` 的当前工具合同及服务端状态；工具未暴露、身份/权限/成本/扫描证据不完整或审批未完成时停止并说明阻断。不得调用宿主 imagegen、第三方 API/provider、CLI、脚本、外部网站或独立 MCP；不得把 brief、提示词、原图、预览或排队任务称为成品。

## 输出格式

使用简体中文，按当前请求删减不相关部分：

```markdown
# Amazon 图片制作计划

## 范围与证据
- Marketplace / 类目 / 页面位置：
- 已检查的 Merchant MCP 结果与商家素材：
- 已确认商品事实：
- 创意建议（待确认）：
- 未知 / 待核对：

## 图片组架构
| 顺序 | 图片类型 | 要回答的买家问题 | 已确认事实依据 | 画面与构图 | 所需素材 | 外观风险 / 待确认项 |
|---|---|---|---|---|---|---|

## 单图制作 brief
- 商品外观锁：
- 目标平台与版位：
- 目标像素 / 宽高比 / 格式（含依据或“待核对”）：
- 构图、视角、光线与背景：
- 已批准文案或事实标注：
- 不得新增或改变：
- 人工复核重点：

## 商家确认与下一步
- 待确认的事实或创意选择：
- 实际图片操作：返回 merchant-marketing，由当前 Merchant MCP 工具和服务端门禁决定是否可执行。
```

## 能力边界

本技能不抓取在线商品/竞品资料，不核验实时平台政策，不提供无依据的市场价格，不访问第三方生产服务，也不生成或编辑图片。它不证明图片符合所有 Amazon 类目规则、不验证实物还原、不授予素材使用权，也不保证审核、转化、排名或销量结果。

# Merchant Studio · 运营概览覆盖规则

> 本页规则覆盖 `design-system/merchant-studio/MASTER.md` 中与运营概览及后台外壳冲突的视觉规则。原 Master 保留，未强制覆盖。

## 设计目标

- 产品：商家运营与营销工作台
- 用户：需要快速判断风险、店铺连接和内容状态的运营人员
- 风格：现代极简企业后台，稳重、清晰、低噪声
- 密度：桌面中高密度；首屏优先呈现关键指标和平台状态

## 视觉规则

- 官方品牌资产使用 `demo/merchant-studio/src/assets/store-nova-primary-horizontal.png`；保持原始宽高比，不裁切、不改色。
- 横版 Logo 在深色侧栏上使用浅色承载面保证黑色字标对比度；登录页直接置于白色卡片表面。

| 角色 | 值 | 用途 |
|---|---|---|
| 品牌深绿 | `#0F4F39` | 主按钮、关键操作、品牌强调 |
| 侧栏深绿 | `#10271F` | 主导航背景 |
| 强调浅绿 | `#D7E98A` | Logo 和当前导航指示线，避免大面积铺色 |
| 页面背景 | `#F3F5F3` | 工作区底色 |
| 卡片表面 | `#FFFFFF` | 指标、数据范围和平台列表 |
| 主文字 | `#17211C` | 标题与关键数据 |
| 次文字 | `#5F6E66` | 描述与辅助信息 |
| 分隔线 | `#DFE5E1` | 卡片边界和列表分隔 |

- 使用离线可靠的系统字体栈，不引入远程字体。
- 标题使用 600–700 字重；正文与标签避免低于 12px，紧凑元数据可使用 10–11px。
- 圆角以 8–12px 为主；阴影只用于层级分离，不做装饰。
- 运营指标合并为统一数据带，用分隔线组织，不为每个指标使用独立彩色卡片。
- 状态必须同时包含文字，不只依赖颜色。

## 布局规则

- 桌面侧栏宽度 224px；主内容最大宽度 1500px。
- 侧栏品牌区只展示官方 Logo；不放置重复的产品副标题和当前商品上下文。知识库二级菜单始终展开，分组标题不显示展开箭头；二级菜单只展示图标和名称，不显示描述小字。
- 运营概览以“今日看板 → 账号看板”为主结构；同步、环境说明和数据范围从该页移除。
- 今日看板采用统一深绿色大面板和“数据 → 素材 → 知识库”三列分区，使用浅绿强调与高对比文字；数据指标采用标签左对齐、数字右对齐的纵向清单，避免窄列中堆叠小卡片。演示数据必须明确标注，规则修改与素材管理提供直接跳转。
- 素材看板的“进入素材库”入口固定在卡片右上角，与标题同层，容量信息区域不再混入跳转操作。
- 账号看板与事务看板为两个独立卡片，以 2:1 比例并排。两者的标题区统一采用英文眉题、中文主标题和说明小字；账号看板集中呈现六个平台的接入状态，平台状态不设置逐项详情入口，说明用户如需连接应联系客户经理，并在固定高度区域展示九家店铺，更多店铺通过区域内滚动查看；事务看板使用更高的独立卡片，将待处理数量置于标题右侧，事项列表使用更高行距填满主要空间并支持内部滚动，不放置冗余的底部总览入口，无待办时使用居中的完成状态。演示连接数据必须明确标注，所有详情入口复用店铺连接页面。
- 1200px 以上的平台连接采用两列；1100px 以下主内容取消侧栏占位，配合现有抽屉导航。
- 页面不得出现横向滚动；长文本优先换行或省略并保留可访问名称。

## 交互与无障碍

- 可点击控件保持至少 36px 视觉高度，主操作与导航目标保持 42–46px。
- 保留可见焦点环、键盘顺序和跳到主要内容入口。
- 悬停只做轻微背景变化，不引发布局位移。
- 遵循现有 `prefers-reduced-motion` 规则。

## 避免

- 大面积亮黄或高饱和渐变。
- 每条信息独立成卡造成碎片感。
- 过多阴影、玻璃效果和无业务含义的动效。
- 同一层级混用多套图标风格或颜色。

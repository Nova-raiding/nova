## 尚未通过的目标验收

1. **本地插件一键授权不可使用。** 在 101 运行中的 API 容器只读核对到 `LOCAL_PLUGIN_ONE_CLICK_ENABLED=false`、集成模式 `local_stdio`；当前 Mac 上无 `Store Nova Connect.app`，无正式 DMG，代码签名身份数为 0，发布所需 `STORENOVA_MAC_SIGNER_THUMBPRINT`、`STORENOVA_MAC_TEAM_ID`、`STORENOVA_MAC_NOTARY_PROFILE` 未配置。代码中的网页按钮、安装实例配对和 PKCE 流程不能替代已签名公证的实际安装、ChatGPT 宿主发现与 `onboarding.status`。不得仅翻开关宣称可用。
2. **贵人鸟商品自动呈现尚未成立。** 店铺是手工登记且商品库为 0；运营导入到当前工作区的路径及真实商品来源尚待验收。不能将其他贵人鸟店铺的商品混入「贵人鸟官方旗舰店」。
3. **全量 E2E 尚未完成。** 当前只覆盖表中场景；平台规则、商品导入、品牌权益、运营全功能、商家全功能、五模态成本、ChatGPT 本地 stdio 宿主均需逐项实机验收。

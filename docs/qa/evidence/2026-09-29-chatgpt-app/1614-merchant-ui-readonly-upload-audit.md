# 生产商家桌面页：知识库上传入口只读验收

时间：2026-09-29 16:14 CST。页面：`https://yxsona.com/`。工具：gstack browse，独立新标签页，桌面视口。账号：`demo@sn.com`；页面所示企业主体为 `QA-DO-NOT-PUBLISH-20260929-120826`。本轮没有选择文件、提交上传、充值或更改业务数据。

## 观察

1. 正式登录接口返回 200，落在 `/merchant/overview`；左侧“知识库”下有“品牌资产”和“素材库”。“品牌资产”进入 `/merchant/products?section=assets`。
2. 品牌资产页的“上传品牌资料”按钮可用；点击打开“上传素材”弹层。目标默认“未归属工作区素材”，分类默认“品牌资料”，支持最多 50 个文件。未选择文件时“确认上传”禁用。页面明确提示文件写入工作区素材库后仍需安全与权益确认才能使用，并提示品牌资料分类、店铺归属与系列暂不由服务端持久化。
3. 弹层的多选文件输入接受 `.xlsx` 和 `.csv`，适合把原始商品表格作为待审核品牌资产上传；同页“选择文档并解析”的另一单文件输入只接受 `.txt,.md,.csv,.json,.doc,.docx,.pdf,.zip`，**不接受 `.xlsx`**。两处入口的文件类型和后续处理语义不一致。
4. 财务概况 `/merchant/finance` 显示当前剩余创意点“未读取”、最近已入账充值“未查到”、创意点流水 0 条；没有显示该工作区享有每月 5000 点。人工发布状态显示“读取失败：服务暂不可用”。本轮只读页面没有触发上传错误，因此不能把它当作上传成功或当前错误文案验证；实际上传被 `CREATIVE_POINTS_UNAVAILABLE` 拒绝的证据见 [1600 上传门禁记录](1600-excel-upload-and-access-gate.md)。
5. 生产界面仍有 `BRAND ASSETS`、`BRAND SETTINGS`、`MATERIAL UPLOAD`、`ACCOUNT & BILLING`、`CREATIVE POINTS`、`MANUAL PUBLISH` 等英文小标题；与“全部返回中文”的用户要求不符。

## 缺陷与建议

- **高：额度阻断缺乏前置说明。** 上传按钮可用，但财务区只写“未读取”，弹层没有告知创意点余额未知会阻断上传。建议在弹层中读取与 API 相同的权益决策并显示明确中文原因和下一步；余额未知时不要暗示可提交成功。
- **中：品牌文档入口不收 XLSX。** 与“上传品牌资料”弹层的 XLSX 支持不一致。建议统一文件类型和文案，并区分“原始素材入库”与“解析并确认商品事实”。
- **中：英文小标题仍可见。** 按国内用户要求翻译这些展示文案，保留技术码仅用于诊断详情。

本轮未复验提交后的上传错误文案，避免对已知权益门禁重复提交两份真实 XLSX。

# 发布记录面板：本地受控浏览器验收

**证据层级：本地 Vite 候选 + 隔离挂载的生产 `PublishHistoryPanel` 组件 + Playwright 只读模拟 API。** 这不是完整商家页面、生产 API、线上部署或 ChatGPT App 的通过证据。完整商家页面在首次模拟启动时进入通用错误恢复页；Vite 日志定位到模拟的工作区指标缺少 `riskItems`，使 `Topbar → actionableIssueItems` 读取 `undefined.filter`。这是模拟背景数据不完整，尚不能据此判断真实完整页面有无故障。本次使用隔离组件挂载收敛面板自身的视觉与交互验收。

运行命令：`node scripts/run-publish-history-browser-local.mjs`。该脚本启动本地 Vite，浏览器仅访问 `127.0.0.1`，拦截 `/api/**` 返回受控模拟数据，结束后停止自己启动的 Vite。验收不写生产数据。

2026-09-29 的单进程终验结果：**Playwright 3/3 通过，相关 Vitest 10/10 通过，商家 TypeScript 检查通过。** 浏览器断言覆盖发布任务第 1/2 页、平台原始拒绝码与字段、跳转任务链接、未知结果禁止重复提交、人工报告第 101 条、第 6/6 页、人工未验证边界、两类空态、中文 503 错误与重试恢复。模拟请求记录显示仅触达只读列表及取得 MCP 测试 token，无业务写入。

# 运营目录 UI 实施与设计检查

日期：2026-10-05；主工作目录 main；未提交、未部署。此报告仅涵盖运营商品目录组件，不涵盖其他 owner 的代购、商家购买或真实插件验收。

## 已实现

`FinancePage.tsx` 接入独立商品目录组件。套餐、权益包、开通费三入口使用现有桌面工作台样式；当前在售与最新草稿分别显示价格、版本和状态，历史只读。当前在售仅以服务端销售指针确认，不把历史批准版本当作在售；读取失败关闭变更入口。

创建/编辑保存新版本；提交、批准、拒绝、上架、下架、归档、删除草稿分别操作，真实权限分开判断。请求携带版本、销售修订号与稳定幂等键；失败保留表单，可先读取状态后重试。审批与销售操作确认展示商品/价格/版本及原因，历史批准对象不提供整身份删除。

价格按整数分提交，周期、有效天数、标准套餐族/级别、批准包版本及权益政策可配置。权益从真实注册表选择；存储使用规范字节，功能权限只允许 0/1；绑定批准包展开的权益只读，调整需选择新包版本。批准政策引用、原阻断项与旧快照保留在新草稿，消费器未知或政策未解决仍由后端禁止发布。新建开通费初始为6期、每期500点；编辑读取实际期数/每期点数，允许1至24期及正整数点数，仅调价保留原赠点，不包含首期费。政策引用采用注册对象 commercial.onboarding/v2，发放按UTC月周年；更改只作用于新版本。

购买到账窗口、政策版本、升级政策版本与显式开启分别配置；`approved` 是新草稿政策配置，不能替代商品审批、上架或服务端报价校验。权益包采用真实目录/引用 API，批准包与销售 SKU 分开治理，包列表不会把尚未批准的 active 行称作可绑定。

## 桌面组件实测

采用真实候选源码的 Vite 页面与 Playwright；隔离 fixture 拦截 `/api/mcp`，明确不是实际鉴权/数据库/API 成功证据。复现脚本：[ops-catalog-component-browser.mjs](ops-catalog-component-browser.mjs)，运行入口 `node docs/qa/package-implementation-2026-10-05/ops-catalog-component-browser.mjs`，依赖当前候选 Vite 19082。

证据：[普通桌面截图](ops-catalog-fixture-desktop.png)、[200%缩放且关闭阴影截图](ops-catalog-fixture-zoom.png)、[机器结果](ops-catalog-browser-fixture.json)。实际验证在售2000元与草稿2500元独立显示；编辑2600元提交260000分、原版本和修订号、月周期及明确升级政策；三个导航入口；200%时下架操作可见且可打开弹窗，通过键盘 Escape 返回。另验证开通费仅调价保留9期×777点的实际源快照，写入注册政策对象及UTC配置；显式退款恢复版本与 cancel_contract 方式进入新草稿。视口1440×900，页面宽度1440、正文字号16px，浏览器 pageerror 为0。金额中间列在缩放时用局部表格横向滚动，固定商品和操作列；不声称所有列同屏。

最终局部测试：安全测试 launcher 的目录10项、原财务页4项，共14/14通过；检查包括销售指针、权限隔离、读取失败关闭操作、规范单位、0/1功能与元数据保留。类型检查使用 `npx tsc -p apps/ops-console/tsconfig.build.json --noEmit --pretty false`；该工作区没有独立 npm typecheck script，首次尝试不存在脚本未运行编译，改用真实配置。最终该命令 exit 0，编译通过；本 owner 文件 git diff --check 通过。

APP UI 七项 litmus：表格用于比较价格版本；主动作明确新增草稿；颜色同时有状态文字；桌面缩放局部滚动；危险变更独立确认；反馈区保留成功/错误；视觉无装饰渐变/卡片墙，关闭阴影后仍可区分页面区域。视觉判断为 B（清晰的既有运营台组件），非完整站点评级。

旅程体验：运营先看在售，安心；打开新版本看到旧值与政策引用，需要谨慎核对；保存后明确“尚需审批上架”，安心；政策阻断保留，知道需补批准规则；出现异常保留输入，需要查询真实状态再重试。没有增加移动端、插件市场或虚构批准流程。

## 追加政策闭合

退款来源恢复配置显示显式开启、批准政策版本与恢复方式；未配置时明确已履约退款受控阻断。cancel_contract 对合同整单退款生效，部分合同金额仍需批准估值；unused_points_only 只允许 point_pack，前端配置与后端真实守卫一致。政策只写入新草稿，仍须目录审批并固化新订单；没有把表单标志当作自动退款成功证据。

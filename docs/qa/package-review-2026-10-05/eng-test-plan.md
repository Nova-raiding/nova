# Test Plan

Generated by /plan-eng-review 2026-10-05；branch main；repo codexSkills。本文件是实施后 QA 要求，本轮未执行新功能。

## Affected Pages/Routes

- Ops 桌面财务中心：套餐/权益包/开通费目录、商业订单、异常对账；沿现有导航，不猜新URL。
- 商家财务中心：我的套餐、购买中心、升级确认、通知；current/未来/待授予分别查看。
- API/MCP：现有 ops.commercial.catalog-v2、订单 payment.verify 与新增包/quote/receipt 契约。
- ChatGPT 本地直装 stdio 插件：同企业权限、到期、模型中转门禁。

## Key Interactions to Verify

- 增查改删草稿、审批、上架、改价、下架、重新上架、归档；草稿不遮在售，历史快照不变。
- 分别修改开通、套餐、包售价；两端新单用新价，有效旧单/quote用旧价；付款前价格变化须重新确认。
- 首购分项开通费和首期；开通赠点六个月每月500，首期另付，不一次给3000。
- Ops明确企业/用户后开户邀请、代购、真实收款输入及分配摘要；足额且依赖满足才授予。
- 当前套餐、未来已付续期和独立权益包各自起止/来源；升级原到期不变。
- 半周期基础→成长1500元、成长→尊享2500元、基础→尊享4000元；连升不可将上次差价当周期基价。
- 合款/分笔/不足/多付/未匹配款，receipt-return不伪造已付单；审批返款冻结金额。
- 上架→outbox→可见成员通知；重新上架新事件，重试不重复，退企业成员看不到私有通知。

## Edge Cases

- 目录/建单同事务竞争：停售或建单先提交结果一致；role bootstrap后租户仍不可直接读写全局目录。
- 同笔真实流水更换内部ID/幂等键/企业重录拒绝；两个付款核验、两个升级、分配vs返款并发，余额守恒、单当前账期，无倒序死锁或重复发放。
- 月末/闰年/自然月、多月已批准政策、worker停机补发/重跑；到期不被错误延长。
- 旧quote源版本变更、下架前旧单、截止前到账后晚核验、核验时已过原期限，已收款待处置可恢复。
- 相同幂等键相同内容重放原结果；同键不同内容冲突；响应丢失查询原单，不重付。
- 未知权益consumer/非法周期/零价/反向价差拒发布或付费下单；不可默认为零。
- 错误/loading/empty/forbidden/409、离页恢复、双击提交、会话失效、长中文名称和大列表。
- 1440×900桌面、200%缩放、键盘/读屏/focus、明确金额确认、去阴影仍可识别操作。
- 租约worker批次中崩溃、通知成员资格改变、游标续跑、大量历史页，不加载全量数据。

## Critical Paths

- 真实 PostgreSQL隔离环境：目录→商家目录→首购→真实核验/授予→点数账本/赠点worker→本地插件同一Workspace准入。
- 真授权桌面Ops：指定客户→代购→收款分配→核验→商家通知/已购→升级→原到期保留。
- 付款/授予/outbox故障注入：原业务幂等恢复，真实到账证据保留，没有资金丢失/重复授予。
- 迁移兼容/关闭新写回滚：旧有效订单核验、已付授予、查询、赠点与到期worker继续；不删业务或容器数据。
- 配置中转：真实鉴权/请求/用量/人民币成本/错误证据；缺配置fail-closed，无外部副作用。

## Evidence gates

先类型检查及风险匹配单元/API，再项目隔离PG runner和role bootstrap、真实桌面、local stdio、worker/container证据，最后release gates。五文件37项既有通过/fixture health/登录页200都不是新销售功能或生产支付验收。采用授权测试资金及可信回执；支付/模型未配置明确阻断。

## Owner整合独立CLI追加的确定分支

普通订单半开到账截止与策略缺失拒建单；分笔跨截止/晚分配/链接重建不延长；未来套餐点数与服务未生效不进可用/预留/消费；floating_append核验排序及已付窗口固定；升级保留旧有效待付续购，确认页提示未来档位；无授予退款不改任何点数、未来退款取消派生计划、升级退款来源/后续依赖校验、开通退款核对依赖、退款不扣其它来源、外部返款成功本地失败保持冻结同意图重试。以上按PRD16.1–2验收，不是已执行测试。

## 已确认的本地缺口

### P0

1. 本地 P0 已清零；生产 P0 仍是外部 relay、平台、支付、存储和部署信任证据缺失。

### P1

1. Ops 六个一级页面已具备 URL 深链、刷新、前进/后退和旧 hash 兼容；商家工作台仍缺 URL 路由，刷新会丢失页面和任务上下文。
2. 发布轮询、timeline 与 feedback 辅助 API 已分别隔离失败、保留上次成功数据并提供独立重试；素材/品牌/health 仍存在强耦合加载路径。
3. 内容审核“带理由接受”已改为结构化弹窗；充值、导入、素材确认、内容修改和发布失败等剩余动作仍依赖原生 prompt/alert，缺少字段级校验和可恢复错误状态。
4. Ops 店铺树作用域、稳定幂等 key、筛选清空、批量发布暂停/恢复/失败项新确认重试、数据删除结构化理由及逐动作 loading 已闭环；运营工单和完整 CRM 导出仍缺失。

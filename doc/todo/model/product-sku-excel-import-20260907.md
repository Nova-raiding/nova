# 运营后台 Excel 商品 / SKU 导入验收

日期：2026-09-07。归属按客户工作区隔离，同一工作区授权成员可读取。

## 实现

任务与内容页面新增「商品与 SKU · Excel 导入」。下载真实 XLSX 模板，每行一个 SKU，相同平台/店铺/商品货号合并；支持颜色、尺码、价格、库存、SKU 图片链接和工作区素材 ID。表格自动安全检查、解析，展示 SKU 预览，确认后调用既有 catalog.import.batch。重复 SKU、缺少 SKU 价格/库存、同货号冲突标题等显示行号，不静默覆盖。

插件通过 catalog.search(scope=workspace) 查询同一数据库商品；按用户选择的 SKU 使用对应事实和原图。图片 URL 作为商品资料保存，不能自动当成已扫描原图；Excel 内嵌图片不在本次支持范围。生成与发布继续使用现有权限、事实和素材校验。

# 店铺选择与平台范围消歧

日期：2026-08-30

## 已落地

插件对话投影新增统一的 `store_options`：每个选项同时包含平台、店铺名、数据来源、面向商家的状态、解释和下一步动作。真实店铺的商品查询动作固定携带 `platform + account_id`；演示店铺不可选择；只有账号记录或未取得读取权限的店铺不会伪装成可用商品来源。

服务端原有的 `catalog.search` 范围校验保持不变：指定店铺必须同时传入平台和账号，未明确范围时阻断，避免跨店铺猜测；任务、生成和发布继续复用同一店铺范围门禁。

## 状态语义

- 演示店铺：仅用于演示，不代表真实店铺。
- 可读取：可以查看商品，但平台发布能力尚未就绪。
- 可读取并发布：已授权可读取，发布仍需审核和交互确认。
- 需要重新授权 / 已撤销 / 仅有账号记录：明确说明当前不可读取的影响。

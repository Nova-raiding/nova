# 商家运营后台登录与插件接入

运营后台支持两种认证方式：

- 本地开发：启动本地安全会话后，点击右上角“登录 / 连接”检查 API 和工作区；页面不会把 Token 写进前端构建产物。
- 生产部署：使用企业 OIDC/SSO。通过 `VITE_OPS_LOGIN_URL` 配置组织登录入口，通过可选的 `VITE_OPS_REGISTER_URL` 配置申请账号入口。没有申请入口时，账号必须由平台管理员在“用户与成员”中邀请并分配角色，后台不会开放匿名注册。

登录成功后，右上角“连接诊断”会显示当前工作区和 ChatGPT 插件接入说明。插件的绑定流程是身份绑定而不是手工复制 Token：在 ChatGPT 中启用“大麦商家营销”，发送“开始使用大麦”，插件会先调用 `workspace.bootstrap`（首次）或 `workspace.health`（恢复），服务端按当前认证主体创建/恢复唯一工作区并返回绑定状态。工作区 ID 只用于租户范围校验，不能替代认证凭据。

如果页面显示“权限未验证”，先完成组织登录并点击“重试权限验证”；如果显示“工作区未配置”，填写真实工作区 ID。所有邀请、角色变更和工作区绑定都会经过服务端授权和审计，不能通过前端强行放行。

# 商家运营后台登录与插件接入

运营后台用户登录统一使用平台运营账号和密码。开发环境可连接本地安全会话完成界面联调；这不是用户可选的登录方式。

运营账号由平台管理员预配或邀请并分配角色；后台不开放匿名注册，也不提供 SSO、OIDC 或其他外部跳转登录入口。生产构建和发布配置只允许账号密码模式。

登录成功后，右上角“连接诊断”会显示当前工作区和 ChatGPT 插件接入说明。插件的绑定流程是身份绑定而不是手工复制 Token：在 ChatGPT 中启用“Store Nova商家营销”，发送“开始使用Store Nova”，插件会先调用 `workspace.bootstrap`（首次）或 `workspace.health`（恢复），服务端按当前认证主体创建/恢复唯一工作区并返回绑定状态。工作区 ID 只用于租户范围校验，不能替代认证凭据。

如果页面显示“权限未验证”，先使用平台运营账号和密码登录，再点击“重试权限验证”；如果显示“工作区未配置”，填写真实工作区 ID。所有邀请、角色变更和工作区绑定都会经过服务端授权和审计，不能通过前端强行放行。
